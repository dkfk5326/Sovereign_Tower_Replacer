# 사용법

## Portrait Replacer

1. Sovereign Tower를 종료합니다.
2. `portrait-replacer/START.bat`을 실행합니다.
3. 자동으로 찾지 못한 경우 `sovereign_tower.pck`를 지정합니다.
4. 원본 PNG 저장 또는 GDRE 검증을 사용하려면 `gdre_tools.exe`를 지정합니다.
5. **PCK 스캔**을 누릅니다.
6. 초상화와 교체할 PNG를 선택합니다.
7. 교체 방식을 선택합니다.
   - **그대로**: 대상 리소스가 허용하면 교체 PNG의 크기를 유지합니다.
   - **맞추기**: 비율을 유지하며 전체 이미지가 보이게 맞춥니다.
   - **자르기**: 대상 크기를 채우고 넘치는 부분을 자릅니다.
8. **적용**을 누릅니다.

일괄 교체에서는 게임 초상화 파일명과 같은 이름의 PNG가 들어 있는 폴더를 선택하면 됩니다.

원래 상태로 되돌릴 때는 **백업 복원**을 사용합니다.

## Font Replacer

1. Sovereign Tower를 종료합니다.
2. 폰트 크기 최적화 기능을 사용하려면 한 번 `pip install fonttools`를 실행합니다.
3. `font-replacer/START.bat`을 실행합니다.
4. 필요한 경우 `sovereign_tower.pck`를 지정합니다.
5. 한글을 지원하는 TTF/OTF 글꼴을 선택합니다.
6. 적용 범위를 선택합니다.
   - **한국어 전체**
   - **기본 글꼴**
   - **대체 글꼴**
7. 특별한 이유가 없다면 **필요하면 폰트 크기 최적화**를 켜 둡니다.
8. **적용**을 누릅니다.

처음 사용할 때 Godot 4.6.2가 자동 다운로드될 수 있습니다. 첫 교체 전에 원본 한국어 글꼴 데이터의 작은 백업을 만듭니다.
