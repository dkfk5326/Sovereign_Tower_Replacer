Sovereign Tower Portrait Replacer 0.7.0

한국어
- sovereign_tower.pck 안의 캐릭터 초상화를 PNG로 교체합니다.
- 게임 PCK와 GDRE Tools 경로를 지정한 뒤 PCK 스캔을 누르세요.
- 개별 교체 또는 파일명이 같은 PNG를 폴더에서 일괄 교체할 수 있습니다.
- 원본 PCK 백업을 자동으로 만들며 Restore backup/백업 복원으로 되돌릴 수 있습니다.
- UI 오른쪽 위에서 한국어/English를 전환할 수 있습니다.

English
- Replaces character portraits stored in sovereign_tower.pck with PNG images.
- Select the game PCK and GDRE Tools, then click Scan PCK.
- Replace one portrait or batch replace PNG files with matching filenames.
- A backup of the original PCK is created automatically and can be restored from the GUI.
- Use the language selector in the upper-right corner to switch between Korean and English.

Requirements
- Windows
- Python 3 with Tkinter
- GDRE Tools for exporting original PNG files and optional validation
- Microsoft Texconv may be installed automatically when required
- Godot 4.6.2 may be downloaded automatically when required

This is an unofficial modding tool and is not affiliated with the developer or publisher of Sovereign Tower.
