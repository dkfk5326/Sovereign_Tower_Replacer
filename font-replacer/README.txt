Sovereign Tower Font Replacer 0.4.0

한국어
- Sovereign Tower의 한국어 NotoSansKR 글꼴을 선택한 TTF/OTF로 교체합니다.
- 게임 PCK를 선택하고 교체할 글꼴을 고른 뒤 Apply/적용을 누르세요.
- 필요한 경우 Godot 4.6.2를 자동으로 다운로드해 게임용 fontdata를 생성합니다.
- 첫 적용 전에 원본 글꼴을 백업하며 GUI에서 복원할 수 있습니다.
- UI 오른쪽 위에서 한국어/English를 전환할 수 있습니다.

English
- Replaces Sovereign Tower's Korean NotoSansKR font with a selected TTF/OTF font.
- Select the game PCK and replacement font, then click Apply.
- Godot 4.6.2 is downloaded automatically when needed to create game-compatible fontdata.
- The original font data is backed up before the first change and can be restored from the GUI.
- Use the language selector in the upper-right corner to switch between Korean and English.

Requirements
- Windows
- Python 3 with Tkinter
- `fonttools` Python package for optional font size optimization (`pip install fonttools`)
- Internet connection on first use if Godot 4.6.2 is not already available

This is an unofficial modding tool and is not affiliated with the developer or publisher of Sovereign Tower.
